## Descrição

O **Hub do Conhecimento** é um sistema desenvolvido com o objetivo de centralizar e facilitar o acesso a conteúdos de Língua Portuguesa, permitindo a consulta de informações organizadas por diferentes categorias.

O projeto foi desenvolvido utilizando tecnologias de Front-End e Back-End, com integração a um banco de dados relacional. O sistema conta com autenticação de usuários por meio de JWT (JSON Web Token), restringindo o acesso às funcionalidades que exigem login, além de oferecer recursos de busca e organização de conteúdos.

Na atualização do projeto, o sistema passou por uma evolução para ampliar sua disponibilidade e acessibilidade. A infraestrutura foi adaptada para utilizar serviços em nuvem, com o Supabase para gerenciamento do banco de dados PostgreSQL e a Vercel para hospedagem da aplicação Web. Também foi desenvolvida uma versão Mobile utilizando React Native, permitindo o acesso às funcionalidades por dispositivos móveis.

## Como executar o Back-End

1. Clone o repositório do projeto.
2. Acesse a pasta principal do projeto.
3. Entre na pasta `BackEnd` pelo terminal.
4. Execute `npm install` para instalar as dependências.
5. Configure as variáveis de ambiente necessárias no arquivo `.env`.
6. Inicie o servidor utilizando o comando definido no `package.json`, como `npm start` ou `node app.js`, conforme a configuração do projeto.

A API poderá ser testada utilizando ferramentas como Insomnia ou Postman, por meio dos endpoints disponíveis.

## Como executar o Front-End Web

1. Clone o repositório do projeto.
2. Acesse a pasta principal.
3. Entre na pasta `FrontEnd` pelo terminal.
4. Execute `npm install` para instalar as dependências.
5. Verifique se as configurações de conexão com a API estão corretas.
6. Execute `npm run dev` para iniciar o ambiente de desenvolvimento.

Após a inicialização, acesse o endereço local apresentado pelo terminal para visualizar a aplicação no navegador.


## Banco de Dados e Infraestrutura em Nuvem

O banco de dados do Hub do Conhecimento utiliza PostgreSQL, hospedado e gerenciado por meio do Supabase. Dessa forma, as informações ficam disponíveis em nuvem e podem ser acessadas pelas aplicações integradas ao sistema.

A aplicação Web é hospedada na Vercel, que permite sua disponibilização na internet e integração com o GitHub para publicação de atualizações.

As credenciais e configurações de conexão são armazenadas por meio de variáveis de ambiente, evitando a exposição de informações sensíveis no código-fonte.


## Dependências e Configurações

Antes de executar o projeto, é necessário instalar as dependências de cada aplicação utilizando:

`npm install`

Também é necessário configurar o arquivo `.env` com as variáveis de ambiente exigidas pelo sistema. Esse arquivo não deve ser enviado ao GitHub, devendo permanecer protegido por meio do `.gitignore`.
