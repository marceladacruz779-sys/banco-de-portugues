======= Como rodar o Back-End
1- Clone o repositório
2- Acesse a pasta principal "projetoFinal-FrontEnd"
3- Acesse a subpasta "Back-End" a partir do comando CD no seu terminal
4- Ainda no terminal, se certifica que as dependências estão conectadas e execute o comando "node app"
5- Você poderá testar a API usando softwares de testes como o Insomnia

======= Como rodar o Front-End
1- Clone o repositório
2- Acesse a pasta principal "projetoFinal-FrontEnd"
3- Acesse a subpasta "Front-End" a partir do comando CD no seu terminal
4- Ainda no terminal, se certifica que as dependências estão conectadas e execute o comando "npm run dev"
5- Você poderá testar a API a partir do acesso da rota correta em seu navegador, enquanto o código estiver rodando

======= caso ainda não tenha as dependencias, dê "npm install"
